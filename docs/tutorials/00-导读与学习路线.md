# 00 · 导读与学习路线

这本教程 accompanies（配套）ai-app-template 仓库本身：仓库里的每一行核心代码
都会在某一篇里被「为什么这样写」地走读一遍。读完你不仅能改这个脚手架，
还能把整套工程范式搬去任何 LLM 应用。

## 三条学习路线

### 路线 A：求职弹药线（约 3 天）

目标：把这个项目讲成 20 分钟的面试故事，经得起三轮追问。

1. [01 为什为需要 AI 应用脚手架](01-为什么需要AI应用脚手架.md) —— 市场判断与定位
2. [03 模型网关](03-模型网关-重试降级熔断.md) —— 最核心的面试弹药，精读代码
3. [06 可观测性与评测](06-可观测性与自动化评测.md) —— 「质量怎么保障」的标准答案
4. [07 面试指南](07-面试指南-把项目讲成故事.md) —— STAR 话术 + 高频追问

### 路线 B：动手复刻线（约 1 周）

目标：不看本仓库，自己写出等价物。

1. [02 CLI 与模板生成器](02-CLI实现-从零写一个模板生成器.md) → 自己实现 `create`
2. [03 模型网关](03-模型网关-重试降级熔断.md) → 先写测试再写实现
3. [04 LangGraph 工作流](04-LangGraph工作流-分层State与条件边.md) → 复刻条件边重试
4. [05 结构化输出](05-结构化输出-包装类与安全解包.md) → 自己的 XxxSet 约定
5. [06 可观测与评测](06-可观测性与自动化评测.md) → 双门槛评测体系
6. [09 自动评测集与回退门禁](09-自动评测集与回退门禁.md)（进阶）→ 生成-固化-签字-判定完整闭环

### 路线 C：教学/授课线（教师用）

每篇末尾的「练习」与「自测题」按课堂设计，可直接当作业。
建议课程顺序 = 路线 B；[设计审查](../design-review.md) 可作为第一节课的
「真实工程决策」案例——它展示了需求如何在约束下收敛。

## 学习前提

- Python 3.10+（会用 dataclass、类型标注、`X | None` 语法）
- 了解 HTTP 基本概念（不需要熟 FastAPI，教程会带）
- 不需要先会 LangChain —— 本项目刻意不依赖它（见 [架构 ADR-3](../architecture.md)）

## 全仓库地图（按调用深度排序）

```
第一层（入口）    src/ai_app_template/cli.py              一条命令发生了什么
第二层（生成）    src/ai_app_template/generator.py        base+变体如何变成项目
第三层（骨架）    templates/base/app/                 生成项目的核心代码
   ├─ llm/        gateway.py router.py fallback.py    ★ 面试弹药密集区
   ├─ graph/      builder.py nodes/                   工作流编排
   ├─ schema/     wrappers.py                         结构化输出约定
   ├─ eval/       run_eval.py                         质量回归
   └─ observability/ langfuse_setup.py                零侵入观测
第四层（变体）    templates/rag-agent/  multi-agent/  同骨架的三种业务形态
```

## 一分钟验证环境

```bash
pip install -e ".[dev]"
pytest -q          # 仓库测试：17 项（含三模板生成校验）
ai-app-template create ../my-app -t rag-agent --yes
cd ../my-app && pip install -e ".[dev]" && pytest -q   # 生成项目离线全绿
```
